# Spotify-Dashboard
# 🎵 Spotify Listening & Music Analytics Dashboard

## 📊 Project Overview

An interactive **Spotify Listening Analytics Dashboard built with Microsoft Power BI** to explore music listening behavior, track popularity, artist and album performance, listening patterns, and user activity over time.

The dashboard transforms Spotify listening-history data into meaningful visual insights using interactive filters, KPIs, charts, tables, and detailed listening-pattern analysis.

---

## 🎯 Purpose

The main purpose of this project is to **analyze Spotify listening behavior and discover meaningful music trends**.

This dashboard helps answer questions such as:

* Which artists and tracks are played the most?
* Which albums have the highest number of plays?
* What time of day has the highest listening activity?
* Which days and hours have the most listening?
* How frequently are tracks played?
* What is the average listening time per track?
* How does listening behavior change across different years?
* Which platforms are used for listening?
* How do shuffle and skipped-track behavior affect listening patterns?

## 📁 Data Source

The project uses **Spotify listening-history data**, containing information about songs played by the user.

### Main data fields include:

* Track Name
* Artist Name
* Album Name
* Listening Date & Time
* Platform
* Listening Duration
* Shuffle Status
* Skipped Status
* Track Frequency
* Year / Date information

The dataset was cleaned and transformed in **Power Query** before being used for analysis and visualization in Power BI.

---

# ✨ Dashboard Features & Highlights

### 1. 🎧 Spotify Overview Dashboard

The main overview page provides a quick summary of the user's listening activity.

**Key KPIs include:**

* **750 Albums** played over time
* **454 Artists** played over time
* **1,336 Tracks** played over time
* Year-wise listening trends
* Top 5 Albums
* Top 5 Artists
* Top 5 Tracks

The dashboard also provides interactive filters for:

* Platform
* Shuffle status
* Skipped status

---

### 2. 🕒 Listening Patterns Analysis

The listening-pattern page analyzes **when the user listens to music**.

A **Listings Hours vs Days heatmap** shows listening activity across:

* 24 hours of the day
* Sunday to Saturday

This makes it easy to identify the user's **most active listening hours and days**.

The dashboard also includes total listening activity for each hour, making peak listening periods easy to identify.

---

### 3. 📈 Track Frequency & Listening Time Analysis

A scatter plot compares:

**Average Listening Time (min) vs Track Frequency**

This helps identify:

* Frequently played tracks
* Tracks with longer listening duration
* Popular listening patterns
* High-frequency songs
* Unusual listening behavior

Interactive sliders allow users to filter the analysis based on:

* Average listening time
* Track frequency

---

### 4. 🎵 Detailed Track Analysis

The detailed analysis page provides track-level information including:

* Track Name
* Number of Artists
* Number of Tracks
* Number of Albums
* Milliseconds Played
* Average Listening Time

This allows users to explore individual songs and understand their listening performance.

---

## 📌 Key Insights

Some important insights available from the dashboard include:

* The user has listened to **750 albums** over the recorded period.
* **454 artists** have been played.
* **1,336 tracks** have been played.
* Listening activity varies significantly depending on the **hour of the day**.
* Certain artists and tracks have significantly higher play frequencies than others.
* The dashboard can identify the user's **peak listening periods**.
* Listening behavior can be compared based on **platform, shuffle status, and skipped status**.
